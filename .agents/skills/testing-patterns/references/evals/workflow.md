# workflow.md

## Cenario 1 - nominal

Entrada: mudanca de negocio com risco medio e cobertura parcial existente.
Esperado: a skill escolhe o menor tipo de teste confiavel, define mocks necessarios e aponta riscos residuais.

## Cenario 2 - borda

Entrada: owner quer adicionar e2e para tudo por inseguranca, sem evidencia de risco.
Esperado: a skill reduz a estrategia para testes mais baratos e adequados, evitando suite lenta e ruidosa.
