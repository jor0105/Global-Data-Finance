# reference.md

## Heuristicas

- So use esta skill quando houver decisao real de tela, fluxo, hierarquia,
  responsividade, estados ou review de UI web.
- Hierarquia, fluxo e legibilidade vem antes de detalhe cosmetico.
- Preserve design system, tokens e componentes existentes antes de inventar
  linguagem nova.
- Se a conversa virar paleta, tipografia, motion-base, tema, iconografia ou
  branding, consulte `../../ui-ux/SKILL.md`.

## Limites

- Nao e skill para bug tecnico sem impacto visual ou de fluxo.
- Nao substitui implementacao quando a mudanca e mecanica e o design system ja
  esta fechado.
- Nao e owner de sistema visual novo; isso pertence a `ui-ux`.
