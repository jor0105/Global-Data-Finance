# frontend-pack

## Scope

Estado, componentes, interacoes, rendering, acessibilidade basica e UX resiliente.

## Checklist

- `FE-STATE`: fluxo de estado evita regressao ou loop?
- `FE-UX`: loading, erro e empty state continuam consistentes?
- `FE-BOUNDARY`: input de usuario continua validado e escapado?

## Heuristics

- `warning` para fluxo fragil ou cobertura ausente em caminho sensivel.
- `nit` para consistencia visual ou legibilidade sem risco funcional.
